# Tauri desktop shell

Rust side of the **Odoo Print Manager** Windows application. The user-facing documentation
(UI, commands, packaging, security) lives in [../docs/DESKTOP.md](../docs/DESKTOP.md).

```
src/
  main.rs       app bootstrap, tray, autostart plugin, invoke_handler registration
  commands.rs   16 Tauri commands (agent control, pairing, gateway config, printers, autostart)
  agent.rs      locate/start/stop/restart the bundled agent — service or detached process
  paths.rs      %PROGRAMDATA%\OdooPrintManager and agent runtime paths
  tray.rs       tray menu, navigation events, hide-on-close
  logging.rs    rotating manager log
```

Configuration: `tauri.conf.json` (window, CSP, bundle targets, bundled agent resources,
NSIS per-machine install, WebView2 `downloadBootstrapper`), `capabilities/` (permissions),
`icons/` (generated by `node ../scripts/generate-icons.mjs`).

Build:

```bash
npm run desktop:vite:build                                     # WebView bundle → dist-desktop/
cargo tauri build --target x86_64-pc-windows-msvc --bundles nsis,msi
```

Requires a Windows host with Rust stable and `cargo install tauri-cli --version "^2"`.
The Rust build is **not** exercised on Linux; CI builds and smoke-tests it on
`windows-latest` (`.github/workflows/build-windows.yml`).
