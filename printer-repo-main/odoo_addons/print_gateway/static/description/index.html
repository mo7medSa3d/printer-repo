Print operations

Print Gateway for Odoo

Route every Odoo document to the right physical printer — branch by branch, destination by destination — through a durable cloud queue, a Windows print agent and a desktop manager. One platform, one operations language, from the ERP to the paper.

Branch → Destination → Document Type → Binding → Printer

What it does

Multi-branch routing

Branches, destinations, document types and printer bindings with priority fallback — no hardcoded printer IDs anywhere.
Native print button

Standard Odoo reports route through the gateway when mapped, and fall back to the normal download when they are not.
Live fleet status

Printers, agents and job history synced from the gateway, with the same status vocabulary used by the desktop manager.

One status language across Odoo, desktop and web

Online · Success Busy · Printing Claimed · Queued Offline · Failed

The add-on ships a scoped brand layer (--pg-* design tokens) applied only to Print Gateway views, so Odoo's native look, behaviour and usability elsewhere stay exactly as they are.
